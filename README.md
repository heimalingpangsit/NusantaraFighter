# Nusantara Fighter

Prototype Android pixel-art fighting game written in Kotlin.

## Current MVP

- Kotlin + Android Canvas
- 320x180 internal pixel-style resolution
- 11 original parody/caricature fighters
- 1 stylized Indonesian civic arena
- Character select
- Player vs CPU
- HP + timer
- Basic attack
- Skill 1
- Skill 2
- Ultimate
- GitHub Actions debug APK build

## Controls

Touch the on-screen controls:

- LEFT / RIGHT: move
- J: jump
- ATK: basic attack
- S1: skill 1
- S2: skill 2
- ULT: ultimate

## Build on GitHub

Push this project to a GitHub repository. GitHub Actions will build:

`app/build/outputs/apk/debug/app-debug.apk`

This is a prototype. Character art is intentionally stylized pixel caricature, not photorealistic likeness.
